# HTML, CSS

Матеріал для тих, хто хоче освоїти HTML і CSS — основні технології для створення веб-сторінок. HTML
використовується для створення структури веб-документів, а CSS — для стилізації та макетування.
Разом ці технології дозволяють створювати привабливі та функціональні сайти.

## Основні теми:

- Вступ до HTML: Що таке HTML, основні теги та їх призначення.
- Структура HTML-документу: Основні елементи документа, такі як <html>, <head>, <body>.
- Теги HTML: Робота з текстом, зображеннями, списками, таблицями, формами, посиланнями.
- Семантичний HTML: Використання семантичних тегів для покращення доступності та SEO.
- Вступ до CSS: Що таке CSS і як він працює з HTML.
- Основи синтаксису CSS: Селектори, властивості, значення та стилі.
- Позиціювання елементів: Використання position, float, flexbox, grid для розміщення елементів на
  сторінці.
- Стайлінг тексту: Шрифти, кольори, розміри, інтервал між рядками та абзацами.
- Медіа-запити та адаптивний дизайн: Створення сайтів, що добре виглядають на різних пристроях.
- Псевдокласи та псевдоелементи: Стилізація елементів на основі їх стану чи структури.
- Анімації та трансформації: Основи анімацій у CSS та застосування їх до елементів.
- Робота з Flexbox: Створення гнучких макетів за допомогою Flexbox.
- Робота з CSS Grid: Створення складних макетів із використанням Grid.
- Респонсивний дизайн: Як зробити веб-сторінки адаптивними та зручними для різних розмірів екрану.
- Інструменти для роботи з CSS: Використання препроцесорів (Sass, Less), оптимізація CSS для
  продуктивності.
